Companies are told to adopt AI. Then they are told to redo everything.

Tools that learn a task by watching someone do it shipped this summer. They work, and they all start with the same sentence: “record the task”. In their tool, for the agent, with a microphone, today.

  • Claude Cowork“Record a skill”July 2026
  • OpenAI Codex“Record & Replay”June 2026
  • Loom“Record for agent”July 2026

That is work companies already did. Years of training videos, internal Looms and vendor tutorials explain to people how to enter an invoice, create a customer, close a case. All of it sits unused, and redoing it takes exactly the time AI promised to save.

And generic assistants can click, but they don’t know your rules: which of the two Transports Lemaire?

Tutorials filmed for people, never read by a machine.

Every tool on the market starts from a fresh recording. We start from what you already filmed.

We feed an existing video into the pipeline: any video in which you can see the screen and hear someone talk. Below, the chain replays the run of 7 November 2026 on invoice row 3, the duplicate supplier rule.

    Three services, each on the step it makes possible.

    Step 2, Listen

    Gladia

    House rules live in the voice, not on the screen. The presenter says which menu to open and which field comes next. Gladia turns that voice into sentences with timestamps, so each sentence lands on the frame it describes.

    Step 5, Read

    H Models API, Holo4

    A screen from 2021 has to be read the way a person reads it: the exact label of a button, the name of a field. Holo4 reads the keyframes with their sentences, writes the steps and the rules, and flags what has probably changed since.

    Steps 6 and 7, Register and Run

    H Agents API

    The skill is registered once and pinned to a revision, so every run says which version it followed. The agent clicks in a real Chrome, and each session has a public replay that can be followed live.

    The weekend’s numbers, failures first.

    The invoices that depend on a house rule come first: a generic assistant has no way to know these rules. Each verdict is a read of the SQL database, not the agent’s word. This is a pilot, not a study.

    Row 27, Café du Coin

    House rule: always 5.5% VAT.

    Nothing created. Dolibarr refused the requested date, 22/11/2026, as being in the future, and the agent stopped and said so instead of changing it. The date was a bug in our test data, fixed since: this run says nothing about the rule.

    fail 10 steps, 147 s, skill revision 1

    Row 3, Transports Lemaire

    House rule: two suppliers share the name, take the one with a SIREN.

    The 2021 video never states this rule, and the skill does not carry it. The agent still picked the third party with a SIREN, and the database holds the invoice. So this row proves nothing about house rules yet: either the screen gives the answer away, or it was a coin toss.

    success 35 steps, 200 s, skill revision 2

    Where the 2021 video stops matching the job, the agent says so.

    In 3 runs of 11, the agent noted where it had to leave the video: the tutorial starts from an approved purchase order with catalog products, the task is a direct invoice with a free line. These are gaps of coverage, not screen changes: no run reported a renamed or moved button. For a vendor, that is still the report that matters: which videos no longer match how the work is done.

    Why we start from the archive

    1. Input

      Any existing video, even one filmed in 2021 for people. Nothing new to record.

    2. Output

      A skill that carries the rules said in the video, registered once and pinned to a revision.

    3. Proof

      Every run read in your database, not in the agent’s report of itself.

    4. Upkeep

      The agent notes where it had to leave the video. A repair script turns those notes into the next skill revision: built, not run this weekend.
