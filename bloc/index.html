Companies are told to adopt AI. Then they are told to redo everything.

Tools that learn a task by watching someone do it shipped this summer: Claude Cowork “Record a skill” (July 2026), OpenAI Codex “Record & Replay” (June 2026), Loom “Record for agent” (July 2026). They work. They all start with the same sentence: record the task. In their tool, for the agent, with a microphone, today.

That is work companies already did. Years of training videos, internal Looms and vendor tutorials explain to people how to enter an invoice, create a customer, close a case. All of it sits unused.

Every tool on the market starts from a fresh recording. We start from what you already filmed.

The pipeline keeps 60 of the 106 keyframes, the real screen changes first, and sends them to Holo4 five at a time. Twelve requests read the screens, a thirteenth puts the answer together. What comes out is a skill: steps with their exact labels, fields, exception rules, and what has probably changed since 2021.

Step 2, Listen

Gladia

solaria-3

Half of a tutorial is spoken. The narrator says what to fill in and why, the screen only shows the click. Gladia turns the voice into timestamped sentences, so each sentence lands on the screen it explains.

Step 5, Read

H Models API, Holo4

holo4-27b

Screens from 2021 have to be read the way a person reads them: exact labels, which field takes what, what has probably moved since. Holo4 reads 60 keyframes, five per request, and writes the steps, the fields and the exception rules.

Steps 6 and 7, Register and Run

H Agents API

skill pinned by revision

The skill is registered once and pinned, so every run says which revision it followed. The agent clicks in a real Chrome, its progress is followed live, and each run leaves a public replay you can watch.

Where the 2021 tutorial is out of date

  1. The tutorial creates the invoice from an approved supplier order. The agent created it directly from Billing, Supplier invoices, New invoice, a path the tutorial does not detail.

    seen in 1 of 11 runs

  2. The tutorial uses predefined product lines. The agent used a free product line with the description “Ramettes A4 x20”, which the tutorial never shows.

    seen in 1 of 11 runs

  3. Direct creation from the Billing menu is not covered by the tutorial.

    seen in 1 of 11 runs

  4. The task mentions no supplier order, so the agent created the invoice without one. The tutorial starts from an approved order.

We don’t claim to have invented learning from demonstration. We claim it shouldn’t require a new demonstration. Prior work turns existing videos into documentation (Scribe, Guidde, Trupeer) or distils public tutorials into skills (Resource2Skill, Microsoft, 2026). TimeWarp (arXiv 2603.04949) is the closest research. None of them starts from an organisation’s own archive with its house rules.

What comes next, if it holds.

Software vendors have libraries of tutorials. The agent tells them when a video is no longer enough, so they know when to re-film it. Small businesses running software without an API have recorded trainings. Same pipeline, with your rules written down once.

The same tutorial exists in English and Spanish. If all three give the same procedure, that is a robustness measure. We did not have time this weekend.
