Companies are told to adopt AI. Then they are told to redo everything.

Tools that learn a task by watching someone do it shipped this summer: Claude Cowork “Record a skill” (July 2026), OpenAI Codex “Record & Replay” (June 2026), Loom “Record for agent” (July 2026). They work. They all start with the same sentence: “record the task”. In their tool, for the agent, with a microphone, today.

That is work companies already did. Years of training videos, internal Looms and vendor tutorials explain to people how to enter an invoice, create a customer, close a case. All of it sits unused, and redoing it takes exactly the time AI promised to save.

And generic assistants can click, but they don’t know your rules: which of the two Transports Lemaire?

24 boxes filmed for people, never read by a machine.

Every tool on the market starts from a fresh recording. We start from what you already filmed.

We feed an existing video into the pipeline. Any video, as long as you can see the screen and hear someone talk. Below, the chain replays the run of 7 November on invoice row 3, the duplicate supplier rule.

    Three services, each on the step it makes possible.

    Step 2, Listen

    Gladia

    The house rule is in the voice, not on the screen. The presenter says which menu, which field, in which order. Gladia turns that voice into sentences with timestamps, so each sentence lands on the frame it describes.

    Step 5, Read

    H Models API, Holo4

    A screen from 2021 has to be read the way a person reads it: the exact label of a button, the name of a field, the order of a form. Holo4 reads the keyframes with their sentences and writes the steps, the fields and the rules, and flags what has probably changed since.

    Steps 6 and 7, Register and Run

    H Agents API

    The skill is registered once and pinned to a revision, so every run says which version it followed. The agent clicks in a real Chrome, each session has a public replay, and its steps can be followed live.

    We don’t claim to have invented learning from demonstration. We claim it shouldn’t require a new demonstration. Scribe, Guidde and Trupeer already turn existing videos into documentation, and Microsoft’s Resource2Skill distills public tutorials into skills. None of them connects an organisation’s own archive to executable skills that carry its rules and are checked in its database.

    What comes next, if it holds.

    Software vendors have libraries of tutorials. The agent tells them when a video is no longer enough, so they know when to re-film it.

    Small businesses that run on software without an API have internal Looms and recorded trainings. Same pipeline, with your rules written down once.

    The same tutorial exists in English and Spanish. If all three produce the same procedure, we have a robustness measure. We didn’t have time this weekend.

    Not built yet: finding the right tutorial from a task description, and an agent that stops and asks a person when a rule from the video is ambiguous instead of guessing.
