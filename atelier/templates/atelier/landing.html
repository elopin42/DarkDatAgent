{# 2. The problem #}

Companies are told to adopt AI. Then they are told to redo everything.

Tools that learn a task by watching someone do it shipped this summer: Claude Cowork “Record a skill” (July 2026), OpenAI Codex “Record & Replay” (June 2026), Loom “Record for agent” (July 2026). They work. They all start with the same sentence: “record the task”. In their tool, for the agent, with a microphone, today.

That is work companies already did. They have years of training videos, internal Looms and vendor tutorials. Hours of footage explaining to people how to enter an invoice, create a customer, close a case. All of it sits unused.

Redoing that content takes time. Exactly the time AI promised to save: you’re asked to redo everything.

And generic assistants can click, but they don’t know your rules: which of the two Transports Lemaire?

The ones who pay for it: small businesses running software without an API on years of training videos, software vendors whose tutorials go out of date with every release, and the accounting firms and non-profits who re-key the same data by hand every month.

{# 3. What we do #}

We start from what already exists.

We feed an existing video into the pipeline. Any video, as long as you can see the screen and hear someone talk. Gladia transcribes the voice. ffmpeg cuts the keyframes. A vision model, Holo4 on the H Models API, writes a procedure from them: a skill in the H Agents API format. An H agent follows it in the software, clicking like a person, and a database read checks that it got it right.

For the demo, the tutorial is the Dolibarr association’s video on supplier invoices, published on February 5, 2021 under a Creative Commons license. The software has changed since. The agent copes anyway, and when it doesn’t, it tells you at which step the tutorial is wrong.

YouTube video → Gladia (voice to text) → ffmpeg (keyframes) → H Models API (procedure) → H Agents API (the agent) → Dolibarr in Docker → SQL check

Devin, Linkup and Stripe are not used.

We don’t claim to have invented learning from demonstration. We claim it shouldn’t require a new demonstration.

Prior work we build on: TimeWarp (arXiv 2603.04949), and Cloudflare’s account of maintaining documentation videos by hand.

{# 7. What it opens #}

What comes next, if it holds.

Software vendors have libraries of tutorials. The agent tells them when a video is no longer enough, so they know when to re-film it.

Small businesses that run on software without an API have internal Looms and recorded trainings. Same pipeline, with your rules written down once.

Accounting firms and non-profits that re-key the same documents: the video of whoever does it best becomes the agent of everyone else.

The same tutorial exists in English and Spanish. If all three produce the same procedure, we have a robustness measure. We didn’t have time this weekend.

Not built yet: finding the right tutorial from a task description with a web search (Linkup), and an agent that stops and asks a person when a rule from the video is ambiguous instead of guessing.
